Play scratch games no matter the device or features available - By @Yiosgio

Thanks to months of testing, i, Yiosgio have came up with the optimal conditions and ways to play scratch games in MORE places than imaginable, lets begin.

- Computers -

by far the most reachable, Try these:

SB3 to Html files converted via turbowarp packager, Uses turbowarp which is best performance, Some devices may block local html files from enabling JavaScript.

In that case scenario you also can try: Scratch SB3 files loading from computer directly, If not available then you also got the scratch website it's self.

Highest chance of accessing scratch.

- Mobile/Phones -

This is when things start getting interesting because NOW we're outside of computers.

Anyways to get games on IOS (not full-screen exactly but its better than nothing) You can read a special article in this website named "Play scratch games offline on IOS/iPhone", It will explain a method using shortcuts you can do right now.

Any other mobile device: File manager (folder that contains again scratch HTML files) you load them into browser. If that doesn't work you always got the scratch website itself, Consider storing sb3 files and loading those.

A high chance but some games are unavailable due to only supporting keyboard. Please at least add mobile support if you don't have it in your scratch games.

- TV -

This one in particular is VERY limited on devices that work so if your TV doesn't have a browser and if does it needs to support HTML5 and JavaScript, not some browser made like 15 years ago.

If your interested in getting your scratch games on TV, consider reading the article "Play scratch games on Android TV"

If your tv doesn't have it you most likely will need to buy a new HDMI device with browsing. I have tried these two so here are the best fits for them

SuperBox: Haven't tried web browsing, but it has file manager that lets me move files, Able to load HTML files so its a big plus since it works offline. Transfer via USB port.

VseeBox: Web browser only, File manager cant move files and won't let me load HTML files so not good when internet goes out.

Lowest chance of working.

In conclusion, Scratch's high support in accessibility allows for additional devices, If you look at something like Godot you will have way less possibilities to play them anytime, anywhere.
